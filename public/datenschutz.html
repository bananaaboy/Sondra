Was auf Ihrem Gerät bleibt

Alles, was Sie öffnen, umwandeln, schneiden, trennen oder messen, wird im Browser beziehungsweise in der App auf Ihrem Gerät gerechnet.

Die Dateien Ihrer Sitzung speichert Sondra im Speicher Ihres Browsers auf diesem Gerät (IndexedDB), damit sie nach dem Schliessen oder einem Update wieder angeboten werden können. Sie werden nicht gesendet. Unter dem Dateinamen oben rechts lässt sich das mit „Sitzung auf diesem Gerät behalten“ abschalten; dabei wird alles Gespeicherte gelöscht, und die Dateien sind wieder weg, sobald Sie den Tab oder die App schliessen. Auf einem fremden oder geteilten Rechner sollten Sie das tun.

Im Speicher Ihres Browsers (localStorage) legt Sondra ausserdem nur Einstellungen ab:

  • sondra:theme: ob Sie das helle oder dunkle Aussehen gewählt haben.
  • sondra:service: die Adresse eines Extraktionsdienstes, den Sie selbst verbunden haben, und Ihre Qualitätseinstellungen dafür. Ein API-Schlüssel wird nie gespeichert.
  • sondra:instances: bis zu sechs Adressen solcher Dienste, die schon einmal geantwortet haben, damit Sie sie wieder auswählen können.
  • sondra:sitzung-behalten: ob die Sitzung auf diesem Gerät behalten wird.
  • sondra:sprache, sondra:sprachmodell: Sprache und Genauigkeit, die Sie für Untertitel gewählt haben.

Diese Einträge verlassen Ihr Gerät nicht. Sie löschen sie, indem Sie in Ihrem Browser die Websitedaten für diese Seite löschen.

Beim Aufruf der Website

Die Website wird von Vercel Inc. (USA) ausgeliefert. Wie jeder Webserver erfasst Vercel bei jedem Abruf technische Angaben: Ihre IP-Adresse, Zeitpunkt, die abgerufene Adresse und die Angaben Ihres Browsers. Das ist nötig, um die Seite auszuliefern und vor Missbrauch zu schützen. Wir werten diese Protokolle nicht aus. Vercel bewahrt sie für eine begrenzte Zeit auf und löscht sie danach nach den eigenen Fristen.

Schriften und alle Bestandteile der Seite kommen vom selben Server. Es werden keine Inhalte von Google Fonts, CDNs oder Analysediensten nachgeladen.

Wenn Sie etwas von einer Adresse laden

Geben Sie unter „Herunterladen“ eine Adresse ein, schickt Ihr Browser diese Adresse an eine Funktion von Sondra auf dem Server (/api/resolve). Sie fragt die Quelle, was dort liegt. Die Datei selbst läuft danach durch eine zweite Funktion (/api/stream) zu Ihnen. Die Quelle sieht dabei die Anfrage vom Server, nicht Ihre IP-Adresse.

  • Sondra speichert weder die Adresse noch die Datei. Beides existiert nur für die Dauer der Anfrage.
  • Die Protokolle des Hostings (siehe oben) können die abgerufene Adresse enthalten, weil sie Teil der Anfrage ist.
  • Ist es eine YouTube-Adresse, fragt die Funktion YouTube (Google) nach den Angaben zum Video.
  • Ist für diese Website ein Extraktionsdienst eingerichtet, wird die Adresse zuerst an diesen weitergegeben. Welcher das ist, erfahren Sie auf Anfrage an die oben genannte E-Mail-Adresse.

Welche Inhalte Sie laden und ob Sie dazu berechtigt sind, liegt bei Ihnen.

Wenn Sie einen eigenen Dienst verbinden

Unter „Optionen“ können Sie einen eigenen Extraktionsdienst eintragen. Dann schickt Ihr Browser die Adressen, die Sie laden möchten, direkt an diesen Dienst, ohne Umweg über Sondra. Für die Verarbeitung dort ist, wer den Dienst betreibt, verantwortlich. Einen API-Schlüssel, den Sie angeben, hält Sondra nur im Arbeitsspeicher. Solange ein Dienst verbunden ist, zeigt die Kopfzeile das an.

Das Mikrofon

Sondra greift nur auf Ihr Mikrofon zu, wenn Sie unter „Mikrofon“ selbst auf „Mikrofon einschalten“ drücken und Ihr Browser oder Windows es erlaubt. Pegelanzeige, Probeaufnahme und Einstellen laufen vollständig auf Ihrem Gerät: die Aufnahmen liegen nur im Arbeitsspeicher, werden nicht gesendet und sind weg, wenn Sie den Tab oder die App schliessen — es sei denn, Sie speichern sie selbst. Sobald Sie das Werkzeug verlassen, gibt Sondra das Mikrofon wieder frei.

Bildschirmaufnahme

Sondra nimmt den Bildschirm nur auf, wenn Sie unter „Bildschirm“ selbst auf „Aufnahme starten“ drücken und eine Quelle freigeben; im Browser fragt der Browser, in der App wählen Sie den Bildschirm oder das Fenster aus einer Liste mit Vorschaubildern. Die Aufnahme entsteht auf Ihrem Gerät, wird nicht gesendet und liegt danach in Ihrer Sitzung. Mit „Ton des Rechners“ wird alles aufgenommen, was der Rechner in dieser Zeit abspielt; mit „Mikrofon dazu“ auch Ihr Mikrofon, das beim Beenden wieder freigegeben wird.

Untertitel und Transkripte

Die Spracherkennung unter „Untertitel“ läuft auf Ihrem Gerät. Beim ersten Gebrauch lädt Ihr Browser dafür das Spracherkennungsmodell Whisper (rund 80 MB, bei „Genauer“ rund 250 MB) von Hugging Face (huggingface.co, Hugging Face, Inc., USA). Dabei sieht Hugging Face Ihre IP-Adresse und welches Modell geladen wird — Ihre Aufnahme und der erkannte Text werden nicht gesendet. Das Modell bleibt danach im Speicher Ihres Browsers, spätere Durchgänge brauchen kein Netz.

Eigene Trennmodelle

Wenn Sie für „Spuren trennen“ ein eigenes Modell verwenden, lädt Ihr Browser es von Ihrem Gerät oder direkt von der Adresse, die Sie angeben. Sondra sieht dabei nichts.

Die Windows-App

Die App enthält dieselbe Oberfläche und die beiden Funktionen und führt sie auf Ihrem Rechner aus. Sie ist nur unter 127.0.0.1 erreichbar, also nur von Ihrem eigenen Rechner. Es werden keine Nutzungsdaten, Absturzberichte oder Statistiken gesendet.

  • Das Setup wird über GitHub (GitHub Inc., USA) ausgeliefert. Beim Herunterladen verarbeitet GitHub Ihre IP-Adresse und Verbindungsdaten nach den eigenen Datenschutzregeln.
  • Die mit dem Setup installierte App fragt 20 Sekunden nach dem Start und danach alle sechs Stunden bei GitHub nach, ob es eine neue Fassung gibt, und lädt sie dann im Hintergrund. Dabei sieht GitHub Ihre IP-Adresse und die installierte Version; sonst wird nichts übermittelt. Die Fassung aus dem Microsoft Store fragt nicht selbst, dort aktualisiert der Store.
  • yt-dlp, das Programm für Videoportale, lädt die App erst, wenn Sie ein Portal zum ersten Mal benutzen, von GitHub, und prüft es über seine SHA-256-Prüfsumme. Ist diese Kopie älter als eine Woche, bringt yt-dlp sich beim nächsten Gebrauch selbst über GitHub auf den neuesten Stand.
  • Laden Sie in der App etwas von einer Adresse, geht die Anfrage direkt von Ihrem Rechner an die Quelle. Die Quelle sieht dabei Ihre IP-Adresse. Vercel ist nicht beteiligt.
  • Die App schreibt ein Protokoll nach %APPDATA%\Sondra\sondra.log: Startzeiten, den lokalen Port und Fehlermeldungen. Es bleibt auf Ihrem Rechner und wird nur verschickt, wenn Sie es selbst jemandem geben.
  • Einstellungen und Protokoll liegen in %APPDATA%\Sondra. Nach dem Deinstallieren löschen Sie diesen Ordner, um alles zu entfernen.
