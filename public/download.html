Sondra Studio herunterladen

Für Windows 10 und 11 · kostenlos · quelloffen unter der MIT-Lizenz

Sondra Studio ist ein Medienstudio, das Ton, Video und Bilder vollständig auf dem eigenen Gerät bearbeitet. Die App ist dieselbe Werkstatt wie die Website, im eigenen Fenster.

Setup (.exe)

Rund 130 MB. Installiert für alle Benutzer, lädt Videoportale mit yt-dlp in voller Auflösung und aktualisiert sich selbst.

Setup herunterladen

Rechner mit Arm-Prozessor (etwa Snapdragon): Setup für Arm64

Microsoft Store

Von Microsoft signiert, installiert sich ohne Warnung, Updates über den Store. Wählt x64 oder Arm64 selbst.

Im Store öffnen

Website als App

Ohne Setup: sondra.lizge.ch in Edge oder Chrome öffnen, dann Menü ⋯ → Apps → „Sondra installieren“.

Alle Fassungen mit Änderungen stehen unter GitHub Releases, der Quelltext unter github.com/bananaaboy/Sondra.

Sicherheit & Datenschutz

Sondra Studio ist ein unabhängiges, freies Open-Source-Projekt unter der MIT-Lizenz. Die App läuft zu 100% lokal auf deinem Computer: Keine Benutzerdaten, keine Telemetrie, keine Tracker und keine Server-Kommunikation außer bei vom Benutzer ausdrücklich initiierten Aktionen (z. B. Medien-Downloads oder Sprachmodell-Abruf).

Der vollständige Quellcode ist öffentlich auf GitHub einsehbar und nachvollziehbar.

Warum warnt Windows Defender / SmartScreen?

„Der Computer wurde durch Windows geschützt“ Microsoft Defender SmartScreen hat den Start einer unbekannten App verhindert.

Keine Sorge: Die Datei ist 100% sauber und virenfrei.

Microsoft SmartScreen stuft alle neuen oder seltener heruntergeladenen Programme automatisch als „unbekannter Herausgeber“ ein, wenn sie nicht mit einem teuren Firmen-Zertifikat (EV-Code-Signing, mehrere hundert Euro pro Jahr) signiert sind. Da Sondra ein freies Open-Source-Projekt ist, schlägt SmartScreen rein vorsorglich an.

So führst du die Installation aus:
  1. Klicke im blauen Windows-Fenster auf den Link „Weitere Informationen“.
  2. Klicke danach unten rechts auf den Button „Trotzdem ausführen“.
