Sondra Studio herunterladen

Für Windows 10 und 11 · kostenlos · quelloffen unter der MIT-Lizenz

Sondra Studio ist ein Medienstudio, das Ton, Video und Bilder vollständig auf dem eigenen Gerät bearbeitet. Die App ist dieselbe Werkstatt wie die Website, im eigenen Fenster.

Setup (.exe)

Rund 130 MB. Installiert für alle Benutzer, lädt Videoportale mit yt-dlp in voller Auflösung und aktualisiert sich selbst.

Signatur des Setups

Das Setup soll über die SignPath Foundation signiert werden; die Aufnahme ist beantragt. Bis sie bestätigt ist, ist das Setup unsigniert, und Windows kann beim Start warnen („Weitere Informationen“ → „Trotzdem ausführen“). Die Fassung im Microsoft Store signiert Microsoft.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Only binaries built by the project's GitHub Actions workflow from the source code in github.com/bananaaboy/Sondra are signed. Every signing request is approved manually by the project's approver.

Privacy policy

The installed app checks GitHub for new versions of itself. Apart from that, it transfers information to other networked systems only when the user asks for it: downloading from an address the user enters, fetching yt-dlp when a video site is used for the first time, and loading the speech recognition model on first use. It sends no usage data, crash reports or statistics. Details: Datenschutz (German).
